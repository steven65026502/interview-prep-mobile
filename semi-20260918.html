先談 2 家，再補問 4 家

以下是依自動化、資料整合與新人入口排列的交流優先度，不是公司體質評分。25 家活動名單已核對，但沒有逐家完成財報、勞動紀錄與論壇盡調，也未逐頁讀完各公司所有職缺。

01
優先帆宣系統科技PLC／HMI 軟體；先問台南職缺面議；未證實固定月薪達 56K

已查到：活動有 PLC 軟體職，雇主刊載台南 PLC／HMI 職經歷不拘，涉及自動化程式、測試及 SQL。另有海外儲備，不能與台南職混為一談。

適配判斷：你的資料庫、測試與系統整合可轉移，但 PLC、HMI 與工業現場經驗仍要補，不等於 Python 工作。

「我有 Python、SQL 與 API 專案經驗，但 PLC 還在入門。台南 M6 這份能接受這樣的新人嗎？前三個月怎麼帶？寫程式、現場連線測試各占多少？是否要海外派駐？」

再問：底薪、保證獎金、加班、待命與廠址；公司另有 SCADA 職標示兩年，不能直接當新鮮人名額。

25 家完整名單

以下其餘企業是依活動職類做初篩，不代表公司完全沒有資訊職。先索取對應職缺再判斷，不因名字有「系統」「科技」「專案」便認定是軟體／技術 PM。

你怎麼介紹自己

您好，我是資工學士、通訊碩士，今年剛畢業。碩士專案使用 Python、PostgreSQL 和 API 整合資料，做過時間配對、品質檢查、查詢與結果驗證。我想找自動化軟體、設備資料整合或測試開發的新人職。PLC 和現場控制還在入門，所以想了解你們會怎麼培訓，以及新人第一個專案的工作內容。

用 60 秒講論文

「我的研究不是訓練海流模型，而是把不同日期、格式、時間與位置的資料整理成可查詢、可驗證的系統。我用 Python 處理資料，PostgreSQL 保存結果，Flask API 提供查詢，最後用 QGIS 檢視。這段經驗可延伸到設備資料與異常回查，但我不會把資料分析經驗直接說成已經會操作工業控制設備。」

自動化工作要分清楚
  • 資料／流程自動化：Python、API、SQL，最接近目前作品。
  • PLC／HMI：控制邏輯與人機介面，需要補控制基礎與安全觀念。
  • SCADA／監控：設備狀態、告警、歷史資料與系統串接；實際仍可能含現場測試。
  • 機電／儀電：可能包含配線、安裝、維修及試車，不保證以寫程式為主。
  • 工程案 PM：常重進度、分包商、工安與驗收；不同於軟體產品 PM。
可能聊到的基礎題 · 練習，非公司考古題

設備資料沒更新怎麼查？先確認範圍與最後正常時間，分別查看來源是否有送、網路／服務狀態、API 回應與欄位、資料庫寫入及畫面刷新。保留日誌，先在測試環境重現；不要直接重啟或修改生產控制。

不會 PLC 怎麼回答？「我目前強項是資料處理、SQL 與 API，尚無獨立 PLC 專案經驗，希望先了解團隊使用的控制平台、培訓與安全操作流程。」

AI 怎麼協助？用來理解文件、整理測試案例與除錯假設，仍需驗證程式與資料；不把公司機密或控制參數直接交給外部工具。

每家公司最後一定要問

  1. 職缺編號、正式雇主、部門及實際廠址；是否能選北部職？
  2. 前三個月任務、誰帶、開發與施工／維修比例？
  3. 固定月薪、書面保證月份與變動獎金分別多少？
  4. 輪班、夜間／假日待命、出差、派駐與補償？
  5. 是否有英文、PLC、Python、SQL 或邏輯測驗？能否使用 AI？
  6. 面試與投遞期限，今天現場收履歷後是否還要網路應徵？

56K × 12 = 672K；48K × 14 也等於 672K，但兩個月是否書面保證、首年是否按比例必須另問。活動最高薪、平均分紅與海外津貼都不是個人底薪。
