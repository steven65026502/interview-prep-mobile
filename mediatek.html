Questions

可能追問與回答方向

為什麼想做這份工作？
我想從既有的 Python、資料處理與除錯能力，延伸到 Linux 與 CPU 系統軟體。這份職務若包含實際 C／Python 開發、問題定位及與 CPU 團隊合作，會是我建立底層工程能力的好起點。
你的 C 與 Python 程度如何？
Python 是目前最熟悉的語言，能完成資料處理、API、資料庫與自動化腳本。C 有課程與基礎程式經驗，但尚未累積大型系統專案；我會誠實說明，並以實作題與工作訓練補足。
論文專案和 CPU 軟體有什麼關係？
領域不同，但共通能力是讀取既有程式、釐清資料定義、建立可重現流程、追查錯誤與驗證修改。這些能力能移轉到測試自動化、工具開發與系統問題定位。
你怎麼使用 Claude Code 或 Codex？
我會先界定任務與驗證條件，再讓工具協助搜尋、修改或產生測試；每次都檢查程式差異、執行測試並核對輸出。AI 是加速理解與實作的工具，結果責任仍由我承擔。
遇到程式錯誤怎麼處理？
先縮小可重現案例，確認輸入、預期輸出與錯誤邊界，再看 log、逐層排除資料、環境與程式邏輯問題；修改後會重跑原案例與相關回歸測試。
