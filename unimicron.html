4. class 和 object 有什麼差別？

依據：2023-10 同職稱的公開問題，年代較舊。範例為自行設計的 Python 基礎練習。

「class 定義一種資料和行為的組織方式；object 是依這個類別建立的實例。例如 Device 定義設備有哪些資料，每台設備各自建立一個物件，各有自己的設備編號。」
class Device:
    def __init__(self, device_id):
        self.device_id = device_id

    def describe(self):
        return f"Device {self.device_id}"

a = Device("A01")
b = Device("B02")
assert a.describe() == "Device A01"
assert b.describe() == "Device B02"
assert a is not b

a.device_id = "A03"
assert b.device_id == "B02"

self 是目前實例；__init__ 用來初始化實例資料；describe 是方法。改 a.device_id 不會改掉這個例子的 b.device_id。先理解這些，不必今晚背設計模式。Python 類別教學

1. API 有回應，但其中一個欄位不見了

先問：整個請求失敗，還是只有欄位缺少？欄位必填嗎？原始回應有沒有值？這個資料是否要等非同步工作完成？

「我會先保留請求識別碼，對照來源回應、解析結果和回傳格式，找出資料在哪一層消失。如果是必要欄位缺失，回報明確狀態，不把缺值補成 0。確認是暫時性失敗才考慮有限次重試；不是直接在 return 前加 sleep。」

先回憶：dict、get、None、return

dict 是鍵和值；get 找不到鍵時預設回傳 None。0 可能是有效量測，不能用 if not value 把它當成缺值。return 會結束目前函式並回傳結果。

def read_temperature(payload):
    if not isinstance(payload, dict):
        return {"ok": False, "reason": "invalid_payload"}

    if "temperature" not in payload:
        return {"ok": False, "reason": "missing_field"}

    value = payload.get("temperature")
    if value is None:
        return {"ok": False, "reason": "null_value"}

    if isinstance(value, bool) or not isinstance(value, (int, float)):
        return {"ok": False, "reason": "invalid_type"}

    return {"ok": True, "value": value}

assert read_temperature({"temperature": 0})["ok"]
assert read_temperature({})["reason"] == "missing_field"
assert read_temperature({"temperature": None})["reason"] == "null_value"
assert read_temperature({"temperature": "25"})["reason"] == "invalid_type"
assert read_temperature([])["reason"] == "invalid_payload"

這是缺值與型別檢查練習，不是完整 HTTP 服務。正式版還要確認有限數值、量測範圍、單位、權限和錯誤回應契約。Python 文件

4. SQL：每台設備最新一筆怎麼查？

先回憶：WHERE 篩選列，ORDER BY 排序；要「每組一筆」時，不能只在整張表後加 LIMIT 1。

SELECT device_id, measured_at, temperature
FROM (
    SELECT device_id, measured_at, temperature,
           ROW_NUMBER() OVER (
               PARTITION BY device_id
               ORDER BY measured_at DESC NULLS LAST, id DESC
           ) AS rn
    FROM measurements
) AS ranked
WHERE rn = 1;

PARTITION BY 依設備分組；組內從新到舊編號，取第 1 筆。範例假設 id 是唯一值，同時間用它決定順序；正式資料需定義時間缺失與重複的處理方式。PostgreSQL 文件

卡住時：「這段我目前沒有實作過，我先確認輸入、預期輸出與限制，再用最小範例驗證。」先說推理，不要靠大量術語填空。
